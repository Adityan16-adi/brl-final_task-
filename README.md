# Smart Classroom Backend

This is the backend repository for the Smart Classroom project, built with Node.js, Express, MongoDB, and Firebase Admin SDK.

## 🚀 Tech Stack
- **Node.js** & **Express.js**
- **MongoDB** (Mongoose)
- **Firebase Admin SDK** (Authentication)
